# Проверка объединённой версии

23.09.2026, обновление OpenAI: **115 успешных автоматических проверок**, ошибок приложения в браузере при последнем прогоне не зарегистрировано. Дополнительно прошёл реальный запрос к OpenAI через сервер сайта.

- 59 JS-проверок ядра: рейтинг, подтверждения, публикации, AI-контракт, ошибки, хранение, примеры и завершение; выбор OpenAI и сообщения об ошибках ключа/квоты.
- 10 JS-проверок адаптера: схемы интерфейса, черновик против каталога, низкий рейтинг, атомарность при ошибках ввода/записи, отклики, перезагрузка и сохранение прежних данных.
- 27 Python-проверок HTTP-сервера, конфигурации и AI-шлюза: MIME для app.js/.mjs, JSON, Origin, ответы/ошибки моделей, параметры Responses API, отказ/неполный ответ, защита .env, отсутствие ключа в HTTP-ответах, сохранение настроек, отдельные ошибки запрета сети и TLS. Успешные ответы модели в автоматических тестах подставлены; проверка TLS не отключается.
- 19 проверок в настоящем Chrome через локальный CDP: каталог, фильтр, редактор, AI-демо, ответы, рейтинг, сохранение/подтверждение, публикация с нулевым рейтингом, скрытый черновик, форма отклика, ручные решения, выполнение, экранирование HTML, отсутствие Ollama, отсутствие ключа OpenAI, перезагрузка, мобильное меню.

Chrome запущен в отдельном профиле автоматизации. Данные пользовательского браузера тестами не очищались и не менялись. Визуально проверены каталог и редактор на ширине 1440 px, кабинет бизнеса и каталог на ширине 390 px. Первый headless-запуск падал в GPU-процессе среды; рабочий запуск использовал GPU в процессе браузера с отключённым аппаратным ускорением.

Синтаксис app.js проверен Node.js. HTTP-загрузка объединённой страницы и app.js подтверждена. JS-тесты доступны по /tests.html и используют память вместо localStorage пользователя.

После ввода ключа пользователем обнаружены запрет исходящей сети (Windows 10013) и пустой набор доверенных сертификатов Python/MSYS. Разрешён сетевой доступ, сервер перезапущен, добавлена загрузка доверенного CA-набора certifi при пустом системном хранилище. Реальный POST /api/ai/analyze с provider=openai вернул HTTP 200 за 6,8 секунды, карточку и 10 вопросов. Ответ прошёл обычные проверки схемы и происхождения фактов; ключ не выводился. Эти результаты не гарантируют доступность сети при запуске в иной ограниченной среде.

Живая Ollama не проверена и не настроена. Проверка отсутствующих настроек обоих провайдеров выполнялась до ввода пользовательского ключа; сообщения видны, поля сохраняются, скрытой подмены демо нет. Сохранение/чтение .env проверяется с фиктивными значениями в временных каталогах. Полная авторизация, многопользовательский доступ и реальная модерация не реализованы и не заявляются.

`tests/check_browser.py` воспроизводит браузерную проверку с установленным Chrome для Windows в отдельном профиле. Нужен сервер на порту 8000, pip-пакеты не нужны. Скрипт очищает только хранилище своего тестового профиля.
