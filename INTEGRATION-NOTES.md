# Изменения проверенной сборки

1. Полный вес рейтинга больше не начисляется всем критериям по одному общему совпадению с числом или ролью. Для источника, цели, контакта, результата и пользователей добавлены правила полноты. Текст только из цифр не даёт баллов.
2. Дополнили учебную К4 недостающими синтетическими полями; свежий набор показывает все четыре уровня.
3. Отклики привязаны к ID автора. Другой зарегистрированный профиль не получает чужие предложения в разделе «Мои».
4. Убрано ограничение одного предложения на задачу, отсутствующее в кейсе.
5. Бизнес управляет только своими задачами; в демонстрации можно переключить К1–К5. У новой компании отдельный ID владельца.
6. Подтверждение принятого этапа начисляет +10 баллов однократно, отдельно от рейтинга задачи.
7. Пустая форма не создаёт фиктивную задачу «Новый черновик».
8. Сохраняются последний тестовый профиль, метод/результат проверки, учебный период и активный бизнес. Файлы документов не сохраняются.
9. При выборе подтверждения вузом скрытый ранее выбранный файл не блокирует заявку.
10. Сервер проверяет Host для защиты локального AI-шлюза от DNS rebinding; Origin и Content-Type также проверяются.
11. Добавлена понятная инструкция при открытии по file://, устойчивый Windows-запуск и сообщение при занятом порте.
12. Добавлены регрессионные тесты; отчёты и README приведены в соответствие с этой сборкой.

## Совместимость

Ключ задач `ai-sana.part3.v1` сохранён. Старые данные не удаляются. Данные без ID владельца относятся к своему sourceRef либо К1 для старых пользовательских задач. Старые авторы без ID не присваиваются автоматически текущему студенту. Рейтинг вычисляется новой формулой; исходные цифры старой версии не гарантируются.

Роли и проверки владельца по-прежнему клиентские. Исправление демонстрационной логики не превращает приложение в защищённый многопользовательский сервис.
