# Qalam AI / Alem — объединённый MVP

Интерфейс участника 2 из коммита `2b56e1f2ceee5eb8f8e179f016278091b5838dcc` (`test2`) объединён с модулем участника 3 и согласованными материалами участника 1. HTML, CSS и JavaScript без npm и сборки. Python раздаёт файлы и обслуживает OpenAI и необязательную локальную Ollama.

## Запуск

1. Запустите `start.bat` либо `python server.py` из этой папки. Требуется Python 3.10+.
2. Откройте http://127.0.0.1:8000/ через HTTP, не двойным щелчком по HTML.
3. Обновите страницу, если раньше здесь был тестовый интерфейс участника 3.
4. Выбирайте демонстрационную роль в верхней панели. Кабинет бизнеса управляет всеми учебными задачами.

К1–К5 и пять откликов добавляются один раз. Существующее хранилище `ai-sana.part3.v1` сохраняется, прежние пользовательские задачи не удаляются. На другом порту, в другом браузере или по адресу localhost вместо 127.0.0.1 будет отдельное хранилище. Старый макет участника 2 хранил изменения только в памяти; восстановить его потерянные после перезагрузки правки невозможно.

## Проверка на защите

1. Откройте каталог: К1=35, К2=65, К3=85, К4=93, К5=70. Фильтр «Черновик» оставляет К1 доступной для отклика.
2. Выберите «Бизнес», откройте «Мои задачи» → К1 → «Дополнить задачу».
3. Нажмите «Разобрать запрос и задать вопросы». В режиме «Демо» работает явно обозначенная заглушка. Заполните ответы и перенесите их в карточку.
4. Для воспроизводимого примера раскройте «Ответы заказчика для примера К1» и внесите четыре ответа. Предварительный рейтинг станет 95.
5. «Сохранить черновик» оставляет опубликованный рейтинг 35. Отметьте проверку сведений и нажмите «Подтвердить и сохранить» — каталог получит 95.
6. Выберите «Студент · подтверждён», откройте задачу и отправьте свой отклик с идеей, планом, сроком и HTTP(S)-ссылкой.
7. Вернитесь в кабинет бизнеса, выберите команду, затем «Отметить как выполнено». Можно выбрать несколько команд. Баллы за этапы не начисляются.
8. Обновите страницу: задачи, черновики, отклики, решения и отметки выполнения сохранятся.

## AI

Для облачного OpenAI создайте ключ в проекте своей организации, запустите `configure-openai.bat`, вставьте ключ в локальное окно и выберите на сайте «OpenAI — облачная модель». Пошагово: [OPENAI-SETUP.md](OPENAI-SETUP.md). Ключ хранится в .env на сервере, не в браузерном JavaScript. Модель по умолчанию — gpt-4.1-mini. Запросы расходуют доступные API-кредиты проекта.

По умолчанию используется демо без модели. Есть минимум три уточняющих вопроса, редактируемые ответы и перенос предложений в карточку по отдельной кнопке. AI и демо не подтверждают и не публикуют сведения самостоятельно.

Для уже установленной Ollama запустите её сервис, задайте точное имя установленной модели в PowerShell и перезапустите сервер:

```powershell
$env:OLLAMA_MODEL = 'имя-установленной-модели'
$env:OLLAMA_URL = 'http://127.0.0.1:11434'
python server.py
```

Выберите «Ollama — локальная модель». Без настроенной модели интерфейс покажет ошибку и сохранит поля; скрытого перехода в демо нет. Успешный вызов живой Ollama в этой сборке не проверен. Промпт и схема находятся в `ai-contract.json` и `js/ai.mjs`.

## Файлы и проверки

- `app.js`, `index.html`, `style.css` — интерфейс с интегрированными действиями.
- `js/bootstrap.mjs` — запуск и обработка ошибок хранилища.
- `js/ui-model.mjs` — преобразование ID, карточек и статусов; атомарное сохранение составных действий.
- `js/domain.mjs`, `js/store.mjs`, `js/ai.mjs`, `js/participant-data.mjs` — рейтинг, хранение, AI и примеры.
- `RATING.md` — формула и причины изменения прежних оценок примеров.
- `INTEGRATION-NOTES.md` — найденные несовместимости и принятые решения.
- `VERIFICATION.md`, `test-report.json`, `browser-test-report.json` — результаты проверок.

http://127.0.0.1:8000/tests.html запускает 69 JS-проверок в отдельной памяти и не меняет ваши данные. Серверные проверки: `python -m unittest discover -s tests -p "test_*.py" -v`.

## Границы MVP

Нет серверных аккаунтов, общей базы между устройствами и настоящей проверки студентов. Роли и модерация демонстрационные; они не являются разграничением доступа. Профиль регистрации и состояние проверки живут в памяти страницы. Задачи, отклики и их решения сохраняются локально.

Рейтинг использует формальную эвристику конкретности; он не доказывает смысловую релевантность текста. Нужна проверка человеком. Ссылки example.org в подготовленных откликах — подписанные заглушки.

Общий репозиторий команды: [BAITC-Hacks/hack-9765e6ac-qalam-ai](https://github.com/BAITC-Hacks/hack-9765e6ac-qalam-ai), ветка `main`. Здесь собрана объединённая версия участников 2 и 3 с согласованными материалами участника 1.

Исходные папки `ai-sana-module` и `qalam-ai` сохранены отдельно как прежние версии. Локальная рабочая папка `qalam-ai-integrated` связана с общим репозиторием. ZIP содержит исходники без истории Git и без ключей; после распаковки на другом компьютере настройте собственный API-ключ через `configure-openai.bat`.
