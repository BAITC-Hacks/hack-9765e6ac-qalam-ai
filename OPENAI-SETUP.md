# Подключение OpenAI

1. Откройте https://platform.openai.com/api-keys. Выберите организацию, где применён промокод, и нужный проект.
2. Нажмите **Create new secret key**. Назовите ключ, например, `qalam-ai`. Создавайте обычный проектный API-ключ, не Admin key.
3. Скопируйте ключ. В папке приложения запустите **configure-openai.bat** двойным щелчком.
4. Вставьте ключ в открывшееся окно и нажмите Enter. При вводе символы не отображаются. Дождитесь сообщения «Ключ сохранён».
5. Если сайт ещё не запущен, запустите **start.bat**. Уже обновлённый сервер читает новый ключ без перезапуска.
6. Обновите http://127.0.0.1:8000/ и в редакторе выберите **OpenAI — облачная модель**. Введите описание и нажмите «Разобрать запрос и задать вопросы».

Ключ сохраняется в `.env` рядом с сервером, исключён из Git и архива, не выдаётся браузеру по HTTP. Не отправляйте этот файл команде. В архив передаются только шаблон настройки и код. Переменные окружения OPENAI_API_KEY/OPENAI_MODEL имеют приоритет над .env.

Используется `gpt-4.1-mini` через Responses API со строгой JSON-схемой. Другую совместимую модель можно указать в OPENAI_MODEL. Доступность модели определяется вашим проектом OpenAI. Описание и заполненные поля отправляются в OpenAI после нажатия кнопки; запрос использует API-кредиты. Ограничение ответа — 4000 токенов, автоматических платных повторов нет.

Наличие промокода на $50 не доказывает текущий остаток. Проверяйте баланс/кредиты и лимиты в организации того проекта, которому принадлежит ключ.

Сообщения интерфейса:

- Не настроен — запустите configure-openai.bat.
- Ключ отклонён — проверьте или замените ключ.
- Нет доступа — проверьте проект, разрешения ключа и модель.
- Нет квоты — проверьте доступные кредиты и лимиты проекта.
- Лимит запросов — повторите позже.
- Ответ не прошёл проверку — уточните описание; новые выдуманные сведения и изменённые ответы не принимаются.

Документация: [создание ключа и первый запрос](https://developers.openai.com/api/docs/quickstart), [структурированный ответ](https://developers.openai.com/api/docs/guides/structured-outputs), [модель](https://developers.openai.com/api/docs/models/gpt-4.1-mini).

Подключение проверено с тестовыми ответами и ошибками, а также реальным запросом из локального сайта: HTTP 200, карточка и 10 вопросов, 6,8 секунды (23.09.2026).

Если среда запуска запрещает интернет (Windows 10013), разрешите сетевой доступ либо остановите сервер Codex и запустите start.bat в обычном окне Windows. Некоторые сборки Python/MSYS не имеют корневых сертификатов; сервер использует доверенный набор certifi из установленного пакета либо из pip, если системный набор пуст. Проверка HTTPS остаётся включённой. Если нет ни системных сертификатов, ни pip/certifi, установите certifi в выбранный Python.
