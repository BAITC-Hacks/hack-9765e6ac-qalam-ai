# Подключение OpenAI и Ollama

Демо работает без настройки. Настраивайте живую модель только при необходимости; запросы OpenAI могут расходовать средства API-проекта.

## OpenAI

1. Создайте проектный API-ключ на https://platform.openai.com/api-keys.
2. Запустите `configure-openai.bat` либо `python configure_openai.py` в папке проекта.
3. Введите ключ в локальном окне. Символы не отображаются. Не присылайте ключ в чат.
4. Запустите `start.bat`, откройте редактор и выберите «OpenAI — облачная модель».
5. Нажатие кнопки анализа отправляет описание и заполненные поля в OpenAI. Проверяйте, что в учебном примере нет реальных персональных данных.

Ключ записывается в `.env` рядом с сервером. Этот файл не раздаётся по HTTP и исключён из поставляемого архива. Не включайте его в архивы при дальнейшей передаче. Переменные окружения имеют приоритет над `.env`, в том числе пустые значения.

```text
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4.1-mini
```

В коде используется Responses API, `text.format` с JSON Schema и `strict: true`, `store: false`. Модель по умолчанию оставлена как в исходной версии — gpt-4.1-mini; доступность зависит от проекта. Ограничение ответа 4000 токенов, автоматических повторных платных запросов нет.

Официальная документация: https://developers.openai.com/api/docs/guides/structured-outputs

Ключ не настроен — настройте локально. Ошибка 401 — проверьте ключ. 403 — доступ проекта/модели. 429 — лимит или квота. Некорректный ответ не меняет карточку. При ошибке сертификатов настройте доверенные сертификаты Python; проверка TLS не отключается. При необходимости: `python -m pip install certifi`.

## Ollama

Для уже установленной модели задайте переменные перед запуском сервера:

```powershell
$env:OLLAMA_MODEL = 'точное-имя-установленной-модели'
$env:OLLAMA_URL = 'http://127.0.0.1:11434'
python server.py
```

Выберите локальный режим в редакторе. Молчаливого перехода на демо нет.

## Границы проверки

В этой ревизии проверены форматы запросов, ответы и ошибки с тестовыми подстановками. Реальные OpenAI/Ollama не вызывались. Ранее приложенные отчёты о живых вызовах не являются результатами этой проверки.
